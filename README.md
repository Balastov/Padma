# Padma

Padma — платформа для управления уроками. Первая версия: кабинеты учителя и ученика, серверная авторизация, пользователи, расписание и чат. Дизайн — Frosted Air.
Репозиторий: https://github.com/Balastov/Padma

## Быстрый запуск

Нужен Node.js **22.13+** (или более новый, совместимый с Vite) и npm. Backend использует встроенный `node:sqlite`; на некоторых версиях Node он отмечен как experimental.
Lint и сборка проверены на этом Mac с Node.js 25.6.1 и npm 11.9.0.

```bash
cd /Users/aleksejbalastov/Padma
npm ci
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173). Env-файлы для текущей версии не нужны.
`npm ci` устанавливает версии из package-lock.json и пересоздаёт node_modules.

## Стек и структура

React 19, TypeScript 6, Vite 8, React Router 7, Lucide Icons, CSS, Oxlint. Backend: Node.js HTTP + SQLite, без дополнительных npm-зависимостей.

- `src/main.tsx` — точка входа и BrowserRouter.
- `src/App.tsx` — вход `/`, кабинет ученика `/dashboard`, кабинет учителя `/teacher`, ученики `/teacher/students`, событие `/teacher/new`, настройки `/teacher/settings`.
- `src/pages/` — страницы входа, двух кабинетов, справочника и формы занятия.
- `src/components/` — единый логотип, профиль, календарь, модальное окно, чат и домашние задания.
- `server/` — API, SQLite, хеширование паролей, проверка прав и интеграционные тесты.
- `scripts/` — совместный запуск серверов и безопасная локальная инициализация аккаунтов.
- `public/brand/`, `public/fonts/` — логотипы, локальные шрифты и лицензии.
- `src/styles/global.css` — общие стили; CSS компонентов лежит рядом с ними.
- `src/assets/` и `public/` — изображения и статические ресурсы.
- `vercel.json` — перенаправление маршрутов SPA на index.html; сам по себе не подтверждает наличие работающего deployment.

## Команды

```bash
npm run dev      # Vite (5173) + API (3001)
npm run lint     # Oxlint

```

Интеграционные тесты API и ручные проверки описаны в [DEV.md](DEV.md).

## Первая версия

- Настоящий вход по email и паролю. Сессия хранится в HttpOnly cookie, пароль — только как salted scrypt hash на сервере.
- Роли: владелец, администратор, учитель, ученик, гость. Учитель видит только своих учеников; владелец и администратор — всех. Ограничения проверяет API.
- Добавление и редактирование пользователей, несколько ролей, назначение учителя, фото до 2 МБ. Архивирование учеников/гостей доступно владельцу и администратору.
- Занятия: дата, начало и конец обязательны. Недельный календарь, список на телефоне, повторы до 12 недель, проверка пересечений, отмена отдельного занятия. Всё время — Москва, UTC+3.
- Чат с сохранением в базе, обновление открытого чата каждые 5 секунд.
- Подключение открывает указанную заказчиком комнату Tolk. Это общая ссылка, не API-интеграция.
- Домашние задания: выдача ученику, текстовый ответ и до 5 файлов общим размером 10 МБ, принятие или возврат с комментарием, повторная сдача и история версий. Файлы доступны только участникам и владельцу/администратору.
- Вход по коду и автоматическое восстановление пароля не подключены.

## Начальные аккаунты

В локальной базе созданы две учётные записи из документа заказчика. Используйте выданные там данные. Пароли и сам документ не включены в репозиторий.

Для новой локальной установки на macOS:

```bash
npm run seed:doc -- "/абсолютный/путь/к/документу.docx"
```

Повторный запуск не сбрасывает пароли существующих аккаунтов. Не публикуйте документ или `.data/`.

Данные хранятся в `.data/padma.sqlite`, эта папка исключена из git. Для переноса потребуется отдельная защищённая копия базы.
