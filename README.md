# Padma

Фронтенд платформы для управления уроками. Сейчас реализован интерфейс ученика.

## Стек

- React + TypeScript + Vite
- React Router
- Lucide Icons

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

## Страницы

- `/` — авторизация
- `/dashboard` — кабинет ученика

Логин пока демо: любые данные → кнопка «Войти» открывает дашборд.

## Адаптив

- ПК: двухколоночный кабинет
- Планшет: колонки друг под другом
- Смартфон: вертикальный стек, чат закреплён снизу
